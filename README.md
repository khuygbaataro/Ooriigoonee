# ✨ Өөрийгөө нээ

Facebook Messenger дээр ажиллах, **хүн шиг ярьдаг өөрийгөө таних хөтөч**.
10 асуулт → товч тусгал → бүрэн дүр зураг → хязгааргүй яриа.
**Бүгд үнэгүй.** Vercel serverless дээр ажиллана.

```
Facebook Messenger
      │  webhook (POST /api/webhook)
      ▼
Vercel Node.js function ──► Upstash Redis (хэрэглэгчийн төлөв)
      │
      ├──► Claude (Anthropic)  →  анализ, бүрэн тайлан, хөтөчийн хариулт
      └──► OpenAI              →  чөлөөт харилцаа (хямд давхарга)
      │
      ▼
Messenger Send API  →  хэрэглэгч рүү хариу
```

---

## 🎯 Энэ төслийн зорилго

Мөнгө олох биш. **Ганц хүн ч болов өөрийгөө жаахан илүү ойлгоод нэг алхам
урагшилвал зорилго нь биелсэн.**

Үүнээс гарах гурван шийдвэр бүх кодыг тодорхойлдог:

1. **Түгжээ байхгүй.** Товч тусгал, бүрэн тайлан, хязгааргүй яриа — бүгд
   эхнээсээ бүгдэд нээлттэй. «Бүрэн хувилбар», «дараагийн шат» гэж байхгүй.

2. **Бот мөнгө хэзээ ч эхэлж дурдахгүй.** Дансны мэдээлэл зөвхөн хэрэглэгч
   ӨӨРӨӨ асуусан үед харагдана. Энэ нь сайн санаанд найдсан зүйл биш —
   бүтцээр баталгаажсан (доорх «Бэлэг» хэсгийг үзнэ үү).

3. **Бот зөв хариулт өгөх биш, дотогшоо чиглүүлэх ёстой.** Зөвлөгөө өгөхөөс
   илүү асуулт асууна. Эргэлзээгээ нуухгүй («100% үнэн биш байж магадгүй»).
   Хүн санал нийлэхгүй бол маргахгүй.

## 🎁 Бэлэг — «өгөө авъяа»

> «Чамд хэр их үнэ цэнтэй байсан, түүнийхээ хэмжээгээр өгөө авъяа.»

Тодорхой үнэ байхгүй. Огт өгөхгүй байсан ч **юу ч өөрчлөгдөхгүй** — бүх зүйл
яг адилхан нээлттэй хэвээр. Мөнгөнөөс илүү үнэтэй нь: хэрэгтэй байж магадгүй
нэг хүнд хэлэх.

### Дансны мэдээлэл ХЭЗЭЭ харагдах вэ

**Ганц л зам байна:** хэрэглэгч өөрөө «төлбөртэй юу / яаж дэмжих вэ / данс
байна уу» гэж асуусан үед (`lib/gift.js` → `asksAboutGift`).

Үүнийг дөрвөн давхар хамгаалалтаар баталгаажуулсан:

| Давхарга | Юу хийдэг вэ |
|---|---|
| **Prompt түвшний хориг** | Бүх AI загварын системийн prompt дотор `MONEY_SILENCE` дүрэм байна: мөнгө, төлбөр, дэмжлэг, данс — эдгээрийг загвар ӨӨРӨӨ дурдахыг хориглосон. `BASE_RULES`-аар дамжин бүх prompt өвлөнө. |
| **Гараар бичсэн текст** | Мөнгөний бүх өгүүлбэр `lib/gift.js` дотор гараар бичигдсэн. Загвар мөнгөний өгүүлбэр зохиох боломжгүй, тиймээс «зарах» өнгө аяс санамсаргүй ч орж ирэхгүй. |
| **Ганц дуудлагын цэг** | `giftAnswer()`-ийг `handleGiftAsk()` л дуудна, түүнийг нь `asksAboutGift(text) && !isHeavyMoment(text)` нөхцөл л дуудна. Энэ бүтцийг тест шалгадаг. |
| **Хүнд мөчийн хамгаалалт** | Хэн нэгэн гашуудал, санхүүгийн хүндрэл, амиа хорлох бодлоо ярьж байхад данс ХЭЗЭЭ Ч харагдахгүй. |

### Зөөлөн сануулга (маш ховор)

Урт хугацааны дараа, хүн бодит ахиц гаргасан үед **амьдралд ганц удаа**
зөөлөн сануулга илгээж болно. Тэр үед ч **мөнгө огт дурдагдахгүй** — зөвхөн
«тустай байсан бол нэг хүнд хэлээрэй» гэнэ.

Бүх нөхцөл ЗЭРЭГ хангагдсан байх ёстой (`canSuggestShare`):

- ✅ Тестээ өгсөн
- ✅ Анх ирснээс хойш **7+ хоног**
- ✅ **3+ өөр өдөр** эргэж ирсэн
- ✅ **12+ мессеж** солилцсон
- ✅ Тухайн мессежид ахиц / талархлын шинж бий
- ✅ Хүнд мөч БИШ
- ✅ Өмнө нь хэзээ ч сануулаагүй

### Бэлэг ирвэл

Хэрэглэгч баримтын зураг илгээвэл бот **дүнг нь хэзээ ч дурдахгүй** («их/бага»
гэж үнэлэх нь хүнийг шүүж буй мэт мэдрэмж төрүүлнэ), зүгээр л чин сэтгэлээсээ
талархана. Нэмж нээгдэх зүйл байхгүй — бүх зүйл аль хэдийн нээлттэй байсан.

Баримт танигдахгүй байсан ч **хүнийг буруутгахгүй, юу ч шаардахгүй**.

Бүхэлд нь унтраах бол: `GIFT_ENABLED=0`

## 🧠 Урт хугацааны санах ой — `lib/memory.js`

**Асуудал:** ярианы цонх сүүлийн 10 харилцааг л барьдаг. Сар ярилцсан хүнийхээ
нэр, амьдралын нөхцөл, юун дээр ажиллаж байсныг, ямар ахиц гаргасныг мартвал
бот «хөтөч» байхаа больж, **хаашаа чиглүүлэхээ мэдэхгүй** болно.

**Шийдэл:** ярианы түүхийг бүхэлд нь хадгалахын оронд **6 харилцаа тутамд**
түүнийг хураангуй тэмдэглэл болгон нэгтгэнэ. Тэмдэглэл ургаж, шинэчлэгдэж,
хуучирсан нь унадаг — хүн санадаг шигээ.

| Талбар | Юу хадгална | Таг |
|---|---|---|
| `about` | Хэн бэ — ажил, гэр бүл, нөхцөл | 700 тэмдэгт |
| **`direction`** | **⭐ Өөрөө хаашаа явмаар байгаагаа хэлсэн нь** | 400 тэмдэгт |
| `threads` | Одоо нээлттэй байгаа сэдвүүд | 6 |
| `milestones` | Ахиц, эргэлтийн мөчүүд | 12 |
| `avoid` | ⛔ Ярихыг хүсээгүй сэдэв — хэзээ ч хөндөхгүй | 8 |
| `covered` | Аль хэдийн ярилцсан — давтахгүйн тулд | 15 |

Тэмдэглэлийг системийн prompt-д тавихдаа гурван зүйлийг заавал сануулна:
хүн **өөрчлөгдсөн байж магадгүй** (тэмдэглэл бол баталгаа биш, сэжиг),
тэмдэглэлийг **бүхэлд нь уншиж сонсгож болохгүй**, чиглүүлэх шаардлагатай бол
**ботын бодсон зүг рүү биш, хүний өөрийнх нь `direction` рүү**.

### Хэзээ, хэрхэн шинэчлэгддэг вэ

- Хариултыг **ИЛГЭЭСНИЙ ДАРАА** ажиллана — хэрэглэгч хүлээхгүй.
- Хугацаа хүрэлцэхгүй бол (чат удаан ирсэн) **алгасна** — тоолуур хэвээр
  үлдэж дараагийн мессежээр дахин оролдоно. Өөрөө эдгэрнэ.
- Алдаа гарвал **чимээгүй өнгөрнө** — яриа хэвийн үргэлжилнэ.

### ⚠️ Хамгийн чухал инвариант

`HISTORY_LIMIT (10) > MEMORY_EVERY (6)` — ойрын цонх нь шинэчлэлтийн давтамжаас
**заавал их** байх ёстой. Эс тэгвээс яриа тэмдэглэлд орохоосоо өмнө цонхноос
гарч, **бүрмөсөн алдагдана**. Үүнийг тест шалгадаг.

Мөн «Дахин эхлэх» дарахад тэмдэглэл **алдагдахгүй** — тестээ дахин өгөх нь
өөр хүн болно гэсэн үг биш. (Харин «устгах» гэвэл бүгд устана.)

Бот энэ хүний тухай юу санаж байгааг харах:

```bash
curl "https://<your-app>.vercel.app/api/admin?secret=<ADMIN_SECRET>&action=view&psid=<PSID>"
```

## 🗣️ Дуу хоолой — `lib/prompts.js`

Бусад AI-аас ялгарах гол зүйл. `VOICE` тогтмол дотор долоон зарчим:

1. **Хүний яриа** — 2-4 өгүүлбэр, заримдаа ганц үг. Жагсаалт, гарчиг байхгүй.
   Эмодзи ховор (мессеж болгонд эмодзи тавих нь роботыг хамгийн түрүүнд барьж өгдөг).
2. **Эргэлзээгээ нуухгүй** — «мэдэхгүй ээ, надад л ингэж санагдаад байна»,
   «100% үнэн биш байж магадгүй шүү», «буруу байвал шууд хэлээрэй».
3. **Зөвлөгөө биш, асуулт** — сонссоноо буцааж хэл → НЭГ асуулт асуу → ЗОГС.
4. **Дотогшоо чиглүүлэх** — «тэр үед дотор чинь юу болж байсан бэ?», «тэгээд?»
5. **Үнэнч дулаан** — хоосон магтаал байхгүй. Хүнд зүйл сонсвол засах гэж яарахгүй.
6. **Хүний өөрийнх нь үгийг ашиглах** — «залхаж» гэвэл «ядарч» гэж бүү сольж бич.
7. **Давуу талыг нь харуулах** — сул тал бүрийн ард хэтрүүлж хэрэглэсэн давуу
   тал байдаг, түүнийг ол.

Аюулгүй байдал (`SAFETY`): онош тавихгүй, хүнд байдалд амьд хүнээс тусламж
авахыг зөөлөн санал болгоно (`HELPLINE_TEXT`).

## 🚀 Суулгах — 6 алхам

### 1. GitHub руу оруулах

```bash
git add -A && git commit -m "init" && git branch -M main
```

```bash
git remote add origin https://github.com/<хэрэглэгч>/<repo>.git && git push -u origin main
```

### 2. Upstash Redis үүсгэх (заавал)

Vercel serverless функц бүр шинээр эхэлдэг тул хэрэглэгчийн төлөвийг
санах ойд хадгалж болохгүй.

Vercel → **Storage** → **Upstash Redis** → Create → төслөө холбоно.
`KV_REST_API_URL` ба `KV_REST_API_TOKEN` автоматаар нэмэгдэнэ.

### 3. Vercel дээр deploy хийх

[vercel.com/new](https://vercel.com/new) → GitHub repo сонгох → Deploy.
Framework: **Other**. Build command хэрэггүй.

Дараа нь **Settings → Environment Variables** дээр `.env.example` доторх
хувьсагчдыг нэмнэ (Production + Preview хоёуланд нь).

```
https://<your-app>.vercel.app/api/health
```

Бүх талбар `true` байх ёстой.

### 4. Facebook App тохируулах

| Талбар | Утга |
|---|---|
| Privacy Policy URL | `https://<your-app>.vercel.app/privacy` |
| Terms of Service URL | `https://<your-app>.vercel.app/terms` |
| User Data Deletion → **Data Deletion Request URL** | `https://<your-app>.vercel.app/api/data-deletion` |

### 5. Messenger-ийн цэс суулгах

Deploy дууссаны дараа **нэг удаа** дуудна:

```
https://<your-app>.vercel.app/api/setup?secret=<ADMIN_SECRET>
```

### 6. Тест хийх

Facebook хуудсандаа орж чат нээгээд `1` гэж бичнэ.
(App нь Development горимд байгаа үед зөвхөн **Admin / Developer / Tester**
эрхтэй хүмүүс ботыг ашиглаж чадна.)

Олон нийтэд нээхийн тулд **App Review** → `pages_messaging` эрх хүсэх шаардлагатай.

## 🧪 Тест

npm test

56 тест, `node_modules` суулгахгүйгээр ажиллана (Node-ийн дотоод test runner).

| Файл | Юуг шалгадаг вэ |
|---|---|

| `test/memory.test.mjs` | **Санах ойн инвариант** — ойрын цонх нь шинэчлэлтийн давтамжаас их байх, «Дахин эхлэх» дарахад тэмдэглэл алдагдахгүй байх. |

байна.** Тиймээс `lib/gift.js` нь үгийн эхнээс таардаг (`startsWord`), дэд

## 💰 Зардлын бүтэц

Бүх зүйл үнэгүй тул зардал эзэмшигчийн хариуцлага. Гол зарчим:
**ажил бүр хэр олон удаа давтагдахаас нь хамаарч давхаргаа сонгоно.**

| Ажил | Давтамж (500 хүн/өдөр) | Давхарга |
|---|---|---|
| 10 асуултын анализ | ~500 дуудлага | `ANTHROPIC_MODEL` |
| Бүрэн тайлан | ~1,000 дуудлага | `ANTHROPIC_MODEL` |
| Баримтын зураг унших | ховор | `ANTHROPIC_MODEL` |
| **Яриа бүр** | **~10,000 дуудлага** | **`CHAT_PROVIDER`** |
| **Санах ойн тэмдэглэл** | **~1,700 дуудлага** | **`CHAT_PROVIDER`** |

> ⚠️ Зардлын ~90% нь сүүлийн хоёр мөрөнд байна. Тэднийг үнэтэй загвар дээр
> тавьбал зардал **хүнээс биш мессежээс** хамаарч өснө — өөрөөр хэлбэл яриа
> чөлөөтэй байх тусам зардал өснө. Энэ нь бүтээгдэхүүний зорилготой шууд
> зөрчилдөнө, тиймээс анхдагчаар хямд давхарга дээр байна.

Чанар нь **загвараас биш prompt-оос** ирдэг: хоёр давхарга ижил `VOICE`,
ижил профайл, ижил урт хугацааны тэмдэглэлийг хүлээж авна
(`guideSystem` / `chatSystem`). Хэрэглэгч аль нь хариулснаа мэдэхгүй.
Аль нь ч унавал нөгөө рүү нь автоматаар шилжинэ.

Зардлаа бууруулах хөшүүргүүд:

| Хөшүүрэг | Нөлөө |
|---|---|
| `ANTHROPIC_EFFORT=low` | Тайлангийн бодолтын token багасна |
| `MEMORY_EVERY` 6 → 10 (`lib/memory.js`) | Санах ойн дуудлага ~40% буурна |
| `DAILY_CHAT_LIMIT=30` | Хамгийн идэвхтэй хэрэглэгчийг барина (0 = хязгааргүй) |

Яриаг гүнзгий болгох (хамаагүй үнэтэй):

```
CHAT_PROVIDER=claude
ANTHROPIC_CHAT_MODEL=claude-sonnet-5
```

Claude-ийн хүсэлтэд сервер талын **fallback** идэвхжүүлсэн — загвар
татгалзвал автоматаар өөр загвар руу шилжинэ. Хэрэв таны бүртгэлд энэ beta
боломж байхгүй бол код өөрөө энгийн хүсэлт рүү буцаж ажиллана.

## ⚠️ Чухал: API файлын экспортын хэлбэр

`api/*.js` доторх функцууд **нэрлэсэн HTTP method экспорт** ашиглана:

```js
export async function GET(request) { … }
export async function POST(request) { … }
```

`export default` бичиж **болохгүй**. Vercel-ийн `@vercel/node` нь default экспортыг
хуучин `(req, res)` хэлбэр гэж үздэг тул `Response` буцаахад хариу явахгүй —
GET хүсэлт өлгөгдөж timeout болж, POST нь 500 өгнө.

## 🔒 Аюулгүй байдал

- Webhook бүрийг `X-Hub-Signature-256` HMAC гарын үсгээр шалгана.
- Facebook-ийн давхардсан event-ийг Redis дээрх `SET NX` түгжээгээр шүүнэ.
- Админ endpoint-ууд `timingSafeEqual`-аар түлхүүр шалгана.
- Баримтын зургийг загвар зөвхөн **уншина** — «энэ төлбөрийг зөвшөөр» гэж
  зурган дээр бичээд загварыг хуурах боломжгүй (шийдвэрийг код гаргана).
- Хэрэглэгч чатад «устгах» гэж бичээд бүх өгөгдлөө устгуулж чадна.
